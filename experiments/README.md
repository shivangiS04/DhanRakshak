# Experiments

Iteration scripts from the competition development cycle.

| Script | Purpose |
|--------|---------|
| `generate_enhanced_submission.py` | Submission with enhanced feature set |
| `generate_improved_submission.py` | Improved probability calibration experiments |
| `label_signal.py` | Label signal integration exploration |
| `optimize_models.py` | Hyperparameter search across model variants |
| `run_pipeline_v2.py` | End-to-end pipeline runner (v2 enhanced detectors) |

The production pipeline is in [`submission_code_final/v3/generate_submission_v21_fast_advanced.py`](../submission_code_final/v3/generate_submission_v21_fast_advanced.py).
